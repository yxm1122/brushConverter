# ABR → Krita 参数矩阵

> **本文件由脚本生成，禁止手改**：数据真身是 `docs/参数矩阵.json`。
> 重新生成：`python tools/render_matrix_md.py`
> 校验：`python tools/check_matrix.py`（每行六栏非空 / verdict 合法 / 键数不低于基线 / 与三份输入 JSON 自洽）
>
> 六栏：**键名 / 语义 / 取值范围（含 clamp）/ 来源 / Krita 对应 / 结论**。
> `verdict` 只允许四个值：`可映射` / `需校准` / `无对应` / `未定`。
>
> 判定口径：
> - **可映射**：Krita 侧有承载字段，换算是精确单位换算或布尔/枚举直映，无经验系数。
> - **需校准**：有承载字段，但需要经验系数、拟合公式、范围裁剪，或已知存在结构性越界。
> - **无对应**：Krita 5.3.3 笔刷预设里没有该语义的承载字段（能力表 45 条 + `docs/parameter-mapping.md` 双证）。
> - **未定**：本轮证据不足（Krita 侧未覆盖该域，或 PS 侧语义未定）；按铁律 4 不猜，登记待 v0.2。
>
> 来源栏（多选）：`abr` = `docs/数据/abr_keys.json` 实测出现过；`re` = `docs/数据/ps_keys.json` 逆向有该键；
> `krita` = 本行在 Krita 能力表/映射表里有明确承载字段；`parser` = 该键作为字符串字面量出现在 `src/brush_converter/**/*.py`。
>
> 带尾随空格的 4CC 键（␠ 代表一个空格，JSON 里是原样空格）：`Cnt␠`、`H␠␠␠`、`Md␠␠`、`Mnm␠`、`Nm␠␠`、`Rpt␠`
