### 4) 11A 参数语义复现（单测断言，精确 0 误差）

- brightness 0/±50/±150：8bit 输出逐像素 == clip(t+b)，无缩放无偏移无 clamp（11A §3.2 表 A 第 1~5 行）；
- contrast 0/±50/±100：输出逐像素 == 127+(clip(t+b)−127)·k(c)（11A §3.2 表 A 第 6~11 行）；
- depth 101 与 100 输出逐像素相同（11A §3.3 表 B 第 21~23 行）；
- PS 号 7/39/40/41 与 Krita 号 0/1/14/15 输出逐像素相同；未知号（99/42/30/10/−1）抛 NotImplementedError 带号。
