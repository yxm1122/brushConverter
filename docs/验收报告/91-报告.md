## 四、关键设计取舍（为什么这么做）

### 4.1 先验收后发布，且发布不可撤回

发布一次就对外可见，回退只能再发一版。所以三道门槛（全量验收 / 隐私门 / 全量回归）全过才允许 `git tag`。

### 4.2 本轮不做功能开关（使用者裁决）

v1.2.0 当时用「开关 + A/B 胜出才转正」留退路；本轮按裁决直接改默认，风险由「每批改前/改后各跑一次全量回归 + 留数字」补偿，回退手段是 `git revert` 到 `85aae49`（v1.2.1）。

### 4.3 人工项不代填

界面类验证（双击 exe、Krita 里导入、目检截图）一律由使用者执行，AI 只给动作与期望结果。
