## 〇、一句话结论

1. **B10 越界区已按裁决落地**：`C=−50 且 |PS 亮度|>127` 时，闭式解反解出的 Krita 亮度越出 [-1,1]，旧行为只能截断到 ±1（掩码空间 8/12 超阈，最大 61.125%/max23）。现在转换器把 PS 的亮度/对比度/反相按 **PS 8bit 链**（C<0 先对比度后亮度；C≥0 先亮度后对比度）烘进内嵌纹理 PNG，Krita 三字段写中性值（B=0、C=1、Invert=false）。**端到端实渲：12/12 = 0.000%/max≤1（改前同批 4/12 通过、8/12 超阈）**。
2. **代价已按裁决接受并登记**：命中区笔刷的纹理亮度/对比度/反相字段在 Krita 里失去 PS 语义（烘死后调整会二次叠加）；旧 .kpp 必须重转（纹理字节/资源名/md5/tEXt 全按新像素派生）；每 (b,c,invert) 组合一份纹理资源（W×H 8bit 灰度 PNG，本组 1.6–12 KB）；**未测**：彩色纹理的灰度权重、B10 与 depth<100 的组合、hardMix 满覆盖 + B10 的组合。
3. **回归与结构检查全绿**：`pytest -q` **344 → 381 passed / 0 failed / 0 skipped**（72.43s，+37 = 新增 35 + B9 记录组 1→3）；三条结构校验 `check_matrix.py` / `render_matrix_md.py --check` / `check_ui_controls.py` 均 exit 0；收尾 tasklist 无 Krita/PS、无 .tmp 锁；受控文件 0 改动。
