## 四、生成参数与代价（发行版实测）

### 4.1 生成位图（Dmtr=200，三档；与 130 记录逐字节一致）

| h | 位图边长 | 内嵌 PNG 字节 | sha256（前 8 位） | 与 130 记录一致 | 正方形 / 边框 255 | `_square_tip` |
|---|---|---|---|---|---|---|
| 0 | 290×290 | 11500 B | `f4f98b81…` | ✅ 逐字节 | ✅ / ✅ 整圈 | no-op（原样返回） |
| 50 | 250×250 | 9529 B | `042b1c6f…` | ✅ 逐字节 | ✅ / ✅ | no-op |
| 100 | 204×204 | 2796 B | `cf5d2fb7…` | ✅ 逐字节 | ✅ / ✅ | no-op |

- 位图边长公式：`L = 2·ceil(r_vis)+2`；`r_vis/R = 1.44 / 1.24 / 1.01`（h=0/50/100，130 §2.2）。
- 截面数据固化：`r4 = round(4r)`、`a2 = round(2α)`（PS 真值是 uint8 中位数 ⇒ 必为整数或半步长），保证"反相后取整"的银行家舍入与 130 完全一致。
- 自检：转换时调用 `verify_generated_tip`（正方形 + 外圈整圈 255，失败即报错），内嵌 PNG 的 md5 与 `brush_definition` 中的 `md5sum` 由同一份字节算出（用例断言）。

### 4.2 尺寸 / 间距语义

| 项 | 公式 | D=200 三档取值 | 依据 |
|---|---|---|---|
| Krita 尺寸字段 | = 位图边长 = PS 实际足印 | 290 / 250 / 204 | 130 §六（硬前置） |
| 计算笔刷 spacing 基准补偿 | `(Dmtr × 短/长) ÷ 位图边长` | 0.689655 / 0.800000 / 0.980392 | 131 表 3：计算笔刷 b_PS=200.00=Dmtr（10/50/100% 三档）；PS 基准是标称直径，Krita 基准变成位图边长，不乘回则 h0 步长被放大 1.45× |
| 采样笔刷 spacing 补偿 | 维持 `spacing × 短/长`（107） | 方形 1.0、非方形 143/183 | 131 表 3/4；本任务未改 |

> 这不是"用系数硬凑"：0.689655 = 200/290 是"PS 标称基准 ÷ Krita 足印基准"的比值本身；两条依据（131 表 3 的 b_PS 实测 + 130 的足印）都可复核。

### 4.3 代价（任务书要求写进报告）

1. **体积**：单支笔刷内嵌位图 = `位图字节 × 4/3（base64）+ XML 开销。D=200 时 h100 的 .kpp 由 5588 → 9143 B（**+3555 B**）；130 的 h0/h50/h100 均值 **+8.6 KB/笔**。样本库 7 支计算笔刷实测位图 398 B–36.7 KB（均值 10.5 KB/支）⇒ **500 支规模按 130 均值约 +4.3 MB**；若大直径居多会更高（D=463 h0 = 670×670 = 36.7 KB/支）。
2. **耗时**：发行版 `convert_presets` 单支（含位图生成 + PNG + 预览 + XML + .kpp 写出）实测 **13 ms（h100） / 17 ms（h50） / 20 ms（h0）/ 41 ms（D=463 h0）**（5 次取中位）；130 报告的 87 ms/笔是含实验装置的保守值。500 支增量约 **7–21 s**，可忽略。
3. **产品语义变化（发布说明必写）**：
   - 笔刷类型由 `auto_brush` 变 `png_brush` ⇒ **Krita 里 hfade/vfade 不可再调**，硬度被烘成像素，要改硬度只能回 PS 重转；
   - **尺寸显示值 = PS 实际足印**（PS 标称 200 的笔刷在 Krita 显示 290/250/204，比值 1.45/1.25/1.02）——这是软边外扩的物理事实，不是换算错误；
   - 旧 .kpp/.bundle 必须重转才能拿到新类型（内容哈希与资源名都变）。
4. **像素级残差**：见 §五 的像素列（1.0%–11.2% / max 4–201），来源是 8-bit 量化 + 1px 网格对齐 + PS 真值自身 AA；**不作本轮判据**。

### 决策 1：间距基准维持"短边"，是否把结论与 PS 自身偏移写进公开文档？
