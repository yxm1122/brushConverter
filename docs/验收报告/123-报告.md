## 一、一句话结论

| 参数 | 结论 | 置信度 |
|---|---|---|
| **Spcn（间距）** | 间距是百分数（内部 clamp 1–1000）；**100% 的基准长度是笔尖蒙版的短边**（= 尺寸 × 短/长），**不是**最大边、**不是**包围盒对角线、**不是**等效直径。现行转换链的短边补偿**已生效**：残差 10%/50% 点 ≤0.2%、100% 点 3.53% | A（单位/范围）+ B（基准） |
| **Hrdn（硬度）** | PS 的软边**伸出标称半径之外**（可见半径 ≈1.45 / 1.24 / 1.03 × 半径，对应 h=0/50/100），Krita 的渐隐**停在半径处**（三个 h 都在 1.00R 归零）→ **结构性不可完全复刻** | B（→ 结构性） |
| **Rndn（圆度）** | 圆度 = **短边/长边（轴比）**，100 = 圆；**不是**面积比（圆度 30 → 实测轴比 0.307，面积比模型应得 0.548）。与 angle 的「旋转+压扁」合成次序 **PS 与 Krita 等价**（三点朝向差 ≤0.001°） | B |
| **Mnm（动态最小值）** | 是每个动态子对象的**输出下限（曲线端点）**，百分比 0–100，不是最终直径的直接折扣 | C（结构位置 A，作用点 C） |
| **Dmtr（尺寸）** | 采样笔尖：**尺寸 = 蒙版最长边**；计算笔尖：尺寸 = 直径（三点互证） | A（转换口径）+ B（PS 侧） |

**没有「未判定」的参数。** 唯一 C 级参数 Mnm 附 5 项拟合交接单（见第五节）。

## 二、关键数字

### 2.1 间距：100% 基准长度的四模型对照（非方形笔尖，长宽比 1.280）

由三点步长反推「基准长度」，再与四个候选模型比：

| 取值 | PS 实测步长 | 反推基准 | 与「短边」模型误差 | 与「最大边」 | 与「包围盒对角线」 | 与「等效直径」 |
|---|---|---|---|---|---|---|
| 10% | 8.78px | 87.80 | **+0.3%** | −21.6% | −38.2% | −11.3% |
| 50% | 43.72px | 87.44 | **−0.1%** | −21.9% | −38.5% | −11.7% |
| 100% | 84.51px | 84.51 | **−3.4%** | −24.5% | −40.5% | −14.6% |

只有**短边**模型落在 ±2% 判据内（两点 ≤0.4%，第三点 −3.4% 属少周期估计偏差）。
→ **PS 与 Krita 的间距残差只有 100% 点 +3.53%；10% / 50% 点 ≤0.2%**。

### 2.2 硬度：两侧剖面端点（尺寸 200，单笔尖）

| 硬度 | PS 可见半径 | PS 10–90% 过渡宽 | Krita 可见半径 | Krita 过渡宽 | 说明 |
|---|---|---|---|---|---|
| 0% | ≈1.45R | 78.75px | **1.00R** | 63.15px | PS 软边外扩 45% |
| 50% | ≈1.24R | 32.38px | **1.00R** | 39.71px | PS 更窄但更靠外 |
| 100% | ≈1.03R | 1.88px | **1.00R** | 0.81px | 硬边，两侧一致（绝对差 ≤2px） |

把过渡宽按各自可见包围盒归一后：**h=0 只差 3.5%，h=50 仍差 34%**。
→ h=0 的 +15.60px 主要是「软边尺寸基准」差（PS 会伸出标称直径外）；**h=50 的 −7.33px 才是真正的曲线形状差**。

### 2.3 圆度与角度

- 尺寸 200、圆度 30 的 PS 蒙版实测 **202 × 62** → 轴比 **0.307**，与「圆度=轴比」的预测 0.30 一致；面积比模型预测 0.548，被否证。
- 角度 0 / 45 / 90 三点的椭圆主轴朝向：PS 0.0001° / 135.0° / 90.0°，Krita 0.0° / 135.0° / 90.0° → **合成次序等价**。

### 2.4 尺寸

计算笔刷标称 20 / 100 / 300px，PS 实测包围盒高 22 / 101 / 301px（+1~2px 为抗锯齿）→ 尺寸 = 直径/最长边，可作基准量。

## 三、可映射性（给校准用）

1. **Spcn**：可映射，公式 = 间距/100 × 尺寸 × （短边/长边）。现有转换链的「短边补偿」方向正确，**不建议撤回**；残差只剩 100% 点 +3.53%。
2. **Hrdn**：**结构性不可完全复刻**。Krita 的渐隐被限制在半径内，PS 的软边在半径外仍有效；h=0 与 h=50 的偏差来源不同（前者尺寸基准、后者曲线形状）。若要等价，只能走「采样笔刷」路线（把 PS 剖面烘成位图），交 v0.14 相应任务做 A/B。
3. **Rndn**：可映射（Krita 圆度/旋转承载），旋转+压扁次序两侧已证等价，无需额外补偿。
4. **Mnm**：转换侧用「尺寸曲线的下限」承载，与「曲线端点」语义同构；PS 侧未量测，故只能到 C，交拟合交接单。
5. **Dmtr**：可映射（笔尖尺寸 + 补平方）。**补平方是刻意做法，本轮未动，也不建议动**。

## 四、与既有结论的冲突（已查清，不需要再猜）

既有偏差报告正文写「非方形笔尖的间距基准被补白换成长边、偏差 32.46%」，而它自己的产物数据显示残差只有 3.53%。本轮把两条对上了：

- 该笔刷在源文件里的真实参数：直径 112、间距 4%、笔尖蒙版 183×143（长宽比 1.280）。
- 现行转换链在生成采样笔刷定义时，会把间距乘以「短边/长边」（=0.781）——即既有的短边补偿。
- 于是 100% 间距下 Krita 的理论步长 = 112 × 0.781 = **87.5px**，与实测 **87.49px** 吻合。
- **111.94px ≈ 112（未乘补偿）**，正是补偿落地之前的数值。

→ **32.46% 是补偿前的旧数字**；现行代码的实际残差是 **3.53%（仅 100% 点）**，10%/50% 点 ≤0.2%。
→ 因此「非方形间距系统性放大 1.28×」在现行代码上**不成立**，不要再据此提出撤回补偿。
→ 测量夹具调用的是发行版同一个笔刷定义函数，所以夹具数字可代表发行版口径；仍建议做一次端到端「转换 + 渲染」作为回归旁证。

## 五、拟合交接单（Mnm，5 项齐全）

| 项 | 内容 |
|---|---|
| 目标参数 | Mnm 的作用点与量纲：是「动态曲线输出下限 × 最终直径」还是「最终直径直接乘 (1−Mnm)」 |
| 拟合函数族 | 分段线性（曲线端点模型）vs 线性缩放（直径折扣模型）；两者对 Mnm=0/25/50/75 给出可区分预测 |
| 统计量 | 同一画笔、同压力序列下 N=40 个笔迹的最小直径中位数，及其对 Mnm 的回归斜率 |
| 最小样本量 | 每档 Mnm ≥ 40 笔迹 × 4 档（0/25/50/75）= 160 |
| 判据阈值 | 两模型预测差 ≥5% 时以中位数 ±3% 判归属；否则登记「统计不可分」 |

## 六、决策项（待使用者追认；本轮按推荐项执行）

**决策 1：间距基准已证为「笔尖短边」，短边补偿撤不撤？**
- **A（推荐）：不撤**。与 PS 语义一致，10%/50% 点残差 ≤0.2%。代价：100% 点仍留 3.53%。
- B：撤回补偿。代码更简单，但非方形笔刷间距会立刻偏约 28%（方向与 PS 相反）。
- C：仅在间距 ≥80% 时加修正系数。能压掉 3.53%，但引入无原文支撑的经验系数。

**决策 2：硬度是否接受「结构性不可复刻」，把等价性交给采样笔刷路线？**
- **A（推荐）：登记结构性 + 交 v0.14 用采样笔刷做 A/B**。残差有明确去向。代价：多一轮实验。
- B：现在改映射拟合 Krita 渐隐。能缩小 h=50 的 7.33px，但会把 h=0 的 15.60px 换成另一种偏差（两侧形状不同，单参数拟合必有一头失真）。
- C：不动，登记已知限制。零成本，但矩阵里永久挂两条残差。

**决策 3：Mnm 只到 C 级，是否接受「先按曲线端点语义实现、v0.14 用拟合交接单裁决」？**
- **A（推荐）：接受**。与现有转换实现对同构，风险低。代价：若 PS 实为「直径折扣」，需改一处映射。
- B：现在就做拟合实验（160 笔迹，约 1.5–2 小时）。一次到位，但超出本族时间盒。
- C：登记「未覆盖」。不阻塞，但与「15 行不许有未判定」冲突。
