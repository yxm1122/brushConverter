- 命名：`<ABR 名去扩展名>_v<版本号>_<8 位逻辑内容哈希>.bundle`（`convert.py:399-400`），哈希是
  「bundle 内 `paintoppresets/` 条目按名字排序，逐个喂『条目名 + 0x00 + sha256(条目字节)』，整体再 sha256 取前 8 位」
  （`kpp/bundle.py:100`），**不是** zip 字节哈希；`.kpp` 命名不变。
- 同内容复用：同目录再转一次 → 同一文件名、同 sha256，并提示 `! 已存在同内容产物，未重复写入`，退出码 0。
- 覆盖防呆：把该 bundle 截断成 1,000 B 后再转 → 生成 `测试用_v1.3.1_656f9dc8_2.bundle`
  （sha256 `8d48cd17d6d314125a90cac29b95e5c72132a35963340672b686423d50cd35d5` / 651,814 B；
  2 字节差来自 `meta.xml` 的 `dc:title` 跟随文件名），**被截断的原文件原样保留（1,000 B）**，
  并提示 `! 目标同名文件内容不同，已重命名为 …（原文件未覆盖）`。
- 回读校验失败路径：`verify_bundle()` 不抛异常，失败写进 `errors`，CLI 打印 `输出校验：失败` + 原因并
  **返回退出码 3**（`cli.py` 的 `cmd_convert`），GUI 在完成对话框追加「产物回读校验失败：<原因>」。
