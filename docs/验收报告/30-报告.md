## 一、任务结论

**✅ 完成（"命中现场"目标达成；"像素消费端是否被定位"如实记为部分完成）**

1. **第一次拿到 PS 2025 上「真硬件断点」的命中现场**：140 次命中、4 个指令点，含指令地址 / 指令字节 / 读或写 / 调用栈 5 层 / 寄存器 / 被监视地址当时的实际取值。
2. **读取点定位到指令级**：纹理结构体 `+0x18`/`+0x1c` 的**读**全部在拷贝层 K60（`0x141ef62c0`/`0x141ef62c6`，各 47 次）；**写**在 H1 内 `0x141a94a97`（15 次）与描述符内核 `0x1412c4e94b`（31 次）。与静态报告对 K60 的「拷贝层」判断**独立吻合**。
3. **「未命中」这次有正向对照**：断点既命中读又命中写、取值序列与 JSX 参数逐值对应（§二·证据 2）。上一轮「监控没生效 vs 真没人读」的不可区分问题**已解决**。
4. **像素消费端仍未判定**：绘制期间没有任何线程读该结构体（DR 覆盖全部 175–176 线程），但 K60 把值拷到**短命副本**，副本之后的去向没打通（实验 004 第二跳被堆复用噪声淹没）。→ 见 §五 遗留 1。

## 四、复现命令（照抄可重跑）

~~~powershell
# 0) 抢 PS 单实例锁（mkdir 原子锁）
$lock = "$env:TEMP\brushconverter-team\locks\ps.lock"
New-Item -ItemType Directory -Path $lock            # 失败=别人持有，退避重试

# 1) 环境（调试器与驱动都在仓库外的临时目录，未入库）
#    %TEMP%\bcdyn30\hwdbg.py      —— ctypes 调试器内核（DEBUG_EVENT/CONTEXT/DR0-DR7/capstone 反汇编）
#    %TEMP%\bcdyn30\exp30.py       —— 实验编排（run 两跳DR / scan 候选计数 / attach-test 空跑）
#    %TEMP%\bcdyn30\bc30_driver.jsx —— PS 侧驱动（ready/go 握手 + 8 步改参数 + 每步 3 笔描边）

$py = '<LOCAL_APP_DIR>\anaconda3\envs\brushConverter\python.exe'
$work = "$env:TEMP\bcdyn30"
$ps  = '<LOCAL_APP_DIR>\PS2025\Adobe Photoshop 2025\Photoshop.exe'
Set-Location $work

# 2) 空跑：只附加不操作（验证调试权限）
$p = Start-Process -FilePath $ps -PassThru; Start-Sleep -Seconds 18
& $py exp30.py attach-test $p.Id "$work\hit-001-raw.json"

# 3) 核心实验：快照点取结构体 + DR 监视 +0x18/+0x1c（= 报告 §3.1）
& $py exp30.py run $ps "$work\bc30_driver.jsx" "$work\work" "$work\hit-003.json" 300

# 4) 两跳：再加 K60 拷贝目标（= 报告 §3.2）
& $py exp30.py run $ps "$work\bc30_driver.jsx" "$work\work4" "$work\hit-004.json" 300

# 5) 候选命中计数（= 报告 §3.3）
& $py exp30.py scan $ps "$work\bc30_driver.jsx" "$work\work5" "$work\hit-005.json" `
   "0x1a8f520,0x1a93ea0,0x1a930b0,0x1a932b0,0x1a93ab0,0x1a937e0,0x1a8af30,0x1ef62b3,0x1a90410,0x1a935f0" 200 15

# 6) 释放锁
Remove-Item -Recurse -Force $lock
~~~

> 关键地址换算：静态 VA `0x14xxxxxxx` 的 RVA = VA − `0x140000000`；运行期地址 = 模块基址 + RVA。断点务必用 **`0x141a93a79`（H1 内部快照点）** 取结构体，**不要**用 `0x141a937e0` 入口（入口 rdi 是栈地址）。
