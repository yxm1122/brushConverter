### 3.4 补：为什么必须用 IDAT 哈希而不是文件 sha256

实测两张**像素完全一致**的 PNG（改值图 vs UI 同参图），文件 sha256 不同：逐字节比对发现 **172 个差异字节全部落在 `iTXt`（XMP：CreateDate/ModifyDate + InstanceID GUID）**，`IDAT` 段逐字节相同。取数命令：

```powershell
& $py "$env:TEMP\bcdyn30a\_diffbytes.py"   # 输出：diff byte count 172 / by chunk Counter({'iTXt': 172})
```

⇒ 「sha256 不同」是必要条件但**不是**像素变化的证据；本任务因此额外提供 `idat_sha256`（`causal-*.json → images.*.idat_sha256`、`diff_*.idat_equal`）。

```powershell
# 0) 抢 PS 单实例锁
New-Item -ItemType Directory -Path "$env:TEMP\brushconverter-team\locks\ps.lock"

$py = '<LOCAL_APP_DIR>\anaconda3\envs\brushConverter\python.exe'
$W  = "$env:TEMP\bcdyn30a"

# 1) 黑盒：对照 + UI 改参（各 12 s）
& $py "$W\runs.py" bb mult_b0_c0   multiply 0   0 "$W\imgs\mult_b0_c0.png"   "$W\work\mult_b0_c0"   240
& $py "$W\runs.py" bb mult_b0_c100 multiply 0 100 "$W\imgs\mult_b0_c100.png" "$W\work\mult_b0_c100" 240

# 2) 改值：K60 读点把 [rbx+0x18] 改成 100（p18；p1c 则改 [rbx+0x1c]）
& $py "$W\runs.py" patch patch_mult_b100 multiply 0 0 "$W\imgs\patch_mult_b100.png" "$W\work\patch_mult_b100" p18 100 240

# 3) 比对（文件 sha256 + IDAT sha256 + imgdiff）
& $py "$W\cmp.py" "$W\imgs\mult_b0_c0.png"   "$W\imgs\patch_mult_b100.png" "$W\cmp\M_x18_vs_ctl.json"
& $py "$W\cmp.py" "$W\imgs\mult_b0_c100.png" "$W\imgs\patch_mult_b100.png" "$W\cmp\M_x18_vs_bb_c100.json"

# 4) 重新汇编 causal-*.json（从 work/*.json + cmp/*.json 重算，幂等）
& $py "$W\make_causal.py"

# 5) 释放锁
Remove-Item -Recurse -Force "$env:TEMP\brushconverter-team\locks\ps.lock"
```

> 说明：`runs.py`（PS 拉起 + 握手 + 黑盒/改值两种模式）、`cmp.py`（sha256 + IDAT + imgdiff）、`make_causal.py`（汇编 JSON）、`bc30a_driver.jsx`（PS 侧出图）全部在 `%TEMP%\bcdyn30a\`，**未入库**（含内部地址，按决策 2 处理）。
