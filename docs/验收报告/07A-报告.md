## 五、可疑点（两种以上假设 + 排除依据）

> 差异表里模式 0/15 的差异都 ≤1 灰度级，没有出现「某模式明显偏高（>10%）」的情况。
> 为防「看似吻合但其实是两个错误互相抵消」，对下面 3 个可疑假设逐一验证并排除。

**H1：真值图不是「纯蒙版」，而是带笔尖覆盖度（base≠1）的整笔渲染，逐像素比较本来就不该相等。**
- 排除依据：模式 0、深度 100% 的 `正片叠底_d100/b0_c0.png` 的 Alpha 与按源码算出的掩码
  **逐像素完全相等**（MAE=0.000，最大差值=0）；乘法语义下只有 base≡1 才可能出现这种相等。
  另外 23 张里所有「无亮度/无对比度调整」的行 MAE 都是 0.000，也指向 base≡1。
- 结论：假设不成立；但该结论只对这批真值图有效（真笔尖有软边，任务 08 必须传真实 base）。

**H2：纹理对齐/缩放取错了，但错误恰好被亮度/对比度补偿，造成「差异很小」的假象。**
- 排除依据：对 (dy,dx) 各 0..63 的平铺平移做扫描，最优平移是 (0,0)，此时「真值/掩码」比值的
  相邻像素差均值 = 0.0073；若假设纹理被双线性拉伸到 100×100，同一比值的标准差 = 1.069、
  粗糙度 = 1.45（比平铺差约 200 倍）。对齐错误会在比值图上留下明显的周期/条纹，这里没有。
- 结论：假设不成立；纹理是 64×64 原尺寸平铺、偏移 (0,0)。

**H3：深度 10% 的语义是「直接把结果乘 0.1」，而不是源码的 strength→10*strength 通道权重。**
- 排除依据：模式 15、深度 10% 的 `线性高度（photoshop）_d10/b0_c0.png` 用两种权重预测：
  取 w=1.0（「直接乘」假设）时 MAE=4.968、最大差值=5 灰度级、99.26% 像素差 >2 灰度级；
  取 w=260/255（源码：强度=round(0.1*255)=26，weight=10*26=260）时 MAE=0.000、最大差值=0。
  最小二乘拟合的最佳 w 为 263.44，与 260 同量级，与 255（w=1）明显不符。
- 结论：假设不成立；深度按 8-bit 量化强度进入合成算子，且 Height 系权重是 10*strength。

**H4（如实标注，未验证）：模式 1/10/14 的公式没有真实 Krita 图对照。**
- 现状：`research/krita结果/` 只有模式 0 与 15；`tests/baselines/krita/` 在执行时为空。
- 处理：只用单测里的 2×2 手算数值断言（公式出处见说明文档 §4），**不宣称「已与 Krita 一致」**。
  等 06A 落盘更多模式的真值图后，应补跑这三行的差异表。
