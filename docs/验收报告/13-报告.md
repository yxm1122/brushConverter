## 六、推导过程（PS → Krita 的闭式逆）

### 6.1 PS 前置变换（任务 12 拟合结果）

中心 `p = 127`（0..255 尺度），对比度因子 `k = 1+C/100`（C<0）或 `1/(1-C/100)`（C≥0），
顺序随符号翻转（`docs/研究报告/lut-拟合.md` §4.1，顺序规则 MAE 0.13 vs 其它 24.85~50.13）：

```text
C >= 0：先亮度（步内先截断到 0..255）后对比度     U = k·clip(t + b) + 127·(1-k)
C <  0：先对比度后亮度                            U = clip(k·t + 127·(1-k) + b)
```

（中间量不提前截断：C<0 时 k≤1，对比度步输出范围是 `[127(1-k), 127+128k] ⊂ [0,255]`，无截断。）

### 6.2 Krita 前置变换（源码）

`KisTextureMaskInfo::recalculateMask()`：`mask -= brightness` → `mask = (mask-0.5)*contrast + 0.5`
→ 统一 clamp 0..1。换成 0..255 尺度、记 Krita 参数为 `(b_k, c_k)`：

```text
U_k = c_k·t - 255·c_k·b_k + 127.5·(1 - c_k)
```

### 6.3 解闭式

**对比度**：两边斜率都要是 `k` → `c_k = k`（Krita 参数正好就是中心乘法因子）。

**亮度**：令常数项相等（`b_k` 记 PS 亮度）：

- C ≥ 0（PS 亮度项带 k）：`k·b + 127(1-k) = -255·k·b_k + 127.5(1-k)`
  → `b_k = (1-k)/(510k) - b/255`
- C < 0（PS 亮度项不带 k）：`127(1-k) + b = -255·k·b_k + 127.5(1-k)`
  → `b_k = (1-k)/(510k) - b/(255k)`

其中 `(1-k)/(510k)` 就是「PS 中心 127 vs Krita 中心 127.5」的半点修正；
C<0 时亮度乘在对比度**之后**，反解到对比度**之前**必须除以 k（直觉：先压平再平移 = 先平移 1/k 再压平）。

**截断区等价性（不是近似）**：
- C<0：k≤1，对比度步不截断；亮度步 PS 在出口统一截断、Krita 也在出口统一截断 → 逐点相同。
- C≥0：k≥1。PS 先把 `t+b` 截到 [0,255] 再乘对比度；Krita 不预先截断。在饱和区：
  底部（b<0, t<|b|）PS 得 `127(1-k) ≤ 0 → 0`，Krita 的同一仿射在该区 `= k(t+b)+127(1-k) < 0 → 0`；
  顶部（b>0, t>255-b）PS 得 `127+128k ≥ 255 → 255`，Krita 在 `t>255-b` 上 `≥127+128k ≥255 → 255`。
  两侧饱和阈值一致，故整段逐点等价。

### 6.4 结构边界（不能硬解的部分）

- `k > 2`（PS 对比度 > 50）：Krita Contrast 上限 2，无解 → 按 2 截断，属结构性失真。
- `b_k ∉ [-1,1]`：由 `b_k = (1-k)/(510k) - b/(255k)` 解出越界条件（C<0）；
  参数网格里 `b=±150, C=-50` 两组（b_k=±1.17~1.18）按边界截断。
- 其余可表达组合的掩码差异 0.00%（最大差 ≤1，纯 8-bit 取整）。

### 6.5 精度选择

- legacy 保持 2 位小数（v1.1.2 行为，不动）。
- calibrated 用 3 位小数：k=2 时亮度舍入误差 `≤0.0005×2×255 ≈ 0.26` 灰度级；
  若用 2 位小数则最大 2.55 级，会在 C=50 的组上产生 5.08% 的 >2 级差异（实测），不满足判据。
- 3 位小数依赖 Krita 用 double 原样读取预设值（`KisTextureOptionData::read` 的 `getDouble`），
  风险与人工抽查见 §五-5。
