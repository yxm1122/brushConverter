### 2.1 命令与口径

```bash
cd <REPO>
export PYTHONIOENCODING=utf-8
PY=<LOCAL_APP_DIR>/anaconda3/envs/brushConverter/python.exe

# 1) 文件数
ls tests/abr-generated/*.abr | wc -l        # → 20

# 2) 逐支解析（等价脚本；本次运行的一次性脚本在 %TEMP%，未入库）
"$PY" -c "
import sys; sys.path.insert(0, 'src')
from pathlib import Path
from brush_converter.abr import AbrFile
for p in sorted(Path('tests/abr-generated').glob('*.abr')):
    a = AbrFile.parse(p)
    print(p.name, a.version, list(a.sections), len(a.tips), len(a.patterns), a.diagnostics)
"

# 3) 逐支转换（只写系统临时目录；converted/ 只读未写）

  b=$(basename "$f" .abr)
  "$PY" cli.py convert "$f" -o "$TEMP/bc112-conv/$b" --no-bundle
done
find "$TEMP/bc112-conv" -name "*.kpp" | wc -l   # → 20
```

### 4.1 优先子集（7 支，时间有限先做这 7 支）

  新建 **640×320** 白底文档，画一条 **160px** 水平直线。应看到：连续的一串圆笔迹（步进≈16px），
  笔头圆形软边，**无纹理颗粒、无上下散开、无椭圆变形**。
- **Krita**：导入 `<VERIFY_DIR>/control-default/kpp/000_BC-v140-control-default.kpp`，选
  `BC-v140-control-default`，同尺寸画布画同一条 160px 直线。应看到与 PS 同形的连续圆笔迹；

#### 2) `spacing-100.abr`（`BC-v140-spacing-100`，非方形间距，验 107 补偿）

- **PS**：该笔刷为**非方形采样笔尖 128×100（宽椭圆）**、直径 112、间距 100%、角度 0（硬度不显示属正常）。

  PS 自身实测 84.5px（−3.4%，少周期估计偏差，属 PS 侧已知）。
- **Krita**：导入 `000_BC-v140-spacing-100.kpp`（预设 `spacing=0.78125` 已含短边补偿），同尺寸画同一条 400px 直线。
  应看到同样的分离椭圆串，中心距 **≈87.5px**。笔迹整体比 PS **高约 1.3–1.5 倍**是补白已知现象，**不算间距不合格**。
- **不合格判据**：Krita/PS 中心距比 **>1.04 或 <0.96**；或 Krita 明显回到改前步长（≈111.94px，+28%，
  表现为 400px 上只有 4–5 个落点）。依据：清单 §2 `spacing-100` 行（107 已知 3.53% 残差，判据放宽 ±4%）。

#### 3) `size-300.abr`（`BC-v140-size-300`，大直径边界）

- **PS**：计算笔刷，直径 **300**、硬度 100、间距 100。新建 **640×400**，画一条 **480px** 水平直线；
