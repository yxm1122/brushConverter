## 三、六条落地逐条

### 135-1 缩放：>100% 预缩放 + Scale=1.0（落地）

- 实现：`convert._prescale_texture_image`（源对齐周期双线性，目标边长 round(边长×s/100)，
  RGB 逐通道同核、8-bit 取整）+ `_texture_xml` 中 s>100 时替换内嵌位图并写 Scale=1.0；
  s≤100 保持原路径写 s/100。两处 Scale 截断解除：convert.py 的 `max(0.01,min(10.0,…))`
  与 preset_xml `_apply_texture` 的同类截断改为原值直写。
- 证据：
  - 预缩放核与 128 的 `tools/exp_texture_scale.prescale_gray` **逐像素相同**
    （test_texture_v150：150/200/300/400 四档 + 非方 40×64 + RGB 逐通道）。
  - 端到端抽检缩放 200%：改前 93.74%/max120 → 改后 0.00%/max1（§2.2）。
  - 收益预期按 128：prescale **24/24 = 0.00% / max≤1、相对残差≤0.34%**；raw 真实纹理
    16/16 超阈（90.03%–94.99%、max 91–123）。本任务抽检 1 档复现同量级。
- 旧基准错在哪：移除前 >100% 交给 Krita 的 Qt 中心对齐重采样，与 PS 差 0.5(k−1) 画布 px
  相位；真实高频纹理上 90%+ 超阈。旧 Scale 截断还会把 >1000% 压成 10。
- 体积代价：见 §六。**边界未测**：<100% 的预缩放核（128 §6.1）不做，保持原路径。
- 非 0 b/c 顺序补测（128 §6.2 登记项）：新增回归 —— b=−27 / C=17 / s=200 时
  ①内嵌 PNG = 原始图案的预缩放（b/c 未烘焙）②b/c 仍为 calibrated 值
  ③掩码空间「重采样→b/c」与 PS 参数化模型差异 0.00%（≤2%/max≤2）。
  **仍未测**：PS 是否先 b/c 再重采样；本任务只按 Krita 既有顺序（先取图案再算 b/c）做假定，
  已登记遗留。

### 135-2 hardMix + 满覆盖：Strength=1.0 + 亮度 ±1/255（落地，仅 base≡1）

- 条件（可解释、有单测）：`texturing_mode == 10` 且 `_tip_is_full_coverage(实际内嵌位图)`
  且深度不随压感。满覆盖 = 位图全 0（深=墨）：只有这种笔尖的 PS 无纹理参考图才
  40000/40000 px 全 255（128A §一 hard 档）；有软边/AA（1..254）或透明区都不算。
- 改动：满足条件时 Strength 强制 1.0（不随 depth）、Brightness += ±1/255
  （Invert=true 取 +1/255，false 取 −1/255；Krita 反相在亮度之后，要让最终掩码抬 1 LSB）。
  输出的 XML：Strength=1、Brightness=0.00392157 / −0.00392157（已写单测固定）。
- 证据：把发出去的参数喂 `tools/texture_mask.compute_mask`（Krita 源码精确复刻）：
  base≡1 时对 0..255 全掩码、Invert 两种状态均恒输出 1.0 —— 与 128A 实测 PS 真值
  「alpha 唯一值 1（全 255）」一致；128A hard 档 3/3 = **0.00% / max0**，
  原路径为 95.573% / 52.377% / 0.975%。
- base<1 不下发：mid（base 均值 0.887）偏置后 27.175/14.040/10.043%、
  soft（0.482）39.657/30.295/26.425%，全部超阈；逐像素预烘焙实测 19.2%–34.9% 且
  须逐 base 烘焙（base 由引擎生成）⇒ 不可落地。**只登记，不改运行时路径。**
- 真实样本：唯一 hardMix 笔刷「KYLE 额外厚实炭笔」位图有 247 个灰度值（非满覆盖）→
  **不下发偏置**，其 1.03% 级残差登记。带压感的满覆盖 hardMix 本轮也不下发
  （偏置阈值随 strength 变，未量测）。

### 135-4 对比度：删 min(2.0,k) clamp（落地）

- 改动：`_texture_brightness_contrast_calibrated` 的 `k_eff = max(0.0, min(2.0, k))` →
  `max(0.0, k)`；对比度上限 2.0 删除（保留 max(0) 防御）；亮度 [-1,1] 截断与
  C 合法域 clamp 保留。
- 精度补充（必须写明）：C>50 区 k 可达 1e6，3 位小数亮度会让阈值偏移
  0.0005×k 个掩码级（C=100 实测 1 个 mask 值翻到两端、max_delta 128）。
  因此 k≤2（旧行为）仍保留 3 位小数，**k>2 的 C>50 区改 9 位小数**；
  Contrast 仍 round 3 位（C=75→4、C=84→6.25、C=100→1e6 均为精确值），
  并新增 `_format_number` 防 1e6 写成「1e+06」。
- 证据：掩码网格 79/81 可表达组合差异比例 **0.00%**、max_delta ≤1（唯一除外的 2 组是
  亮度越界区，见 §七-1）；C=80 的旧 clamp 对照组是 98.935% / max255（128A），
  125 实测 Contrast=4.0 / 1e6 vs PS 真值 0.00% / max0。
- 真实样本：只有「Kyle 的橡皮擦 - 自然边缘」（C=84）受影响，Contrast 由 2.0 → 6.25。
  Krita UI 滑条 0..2 会显示越界值，人工验收项。

### 135-5 minimumDepth：曲线 0 端点写比值 s_m/s_d（落地）

- 改动：`_texture_xml` 压感路径由 `0,s_m;1,1` 改为 `0,s_m/s_d;1,1`（夹到 [0,1]；
  s_d=0 时取 1 保持单调）。`_texture_strength_min` 保留为比值的分子（既有单测仍覆盖）。
- 为什么：Krita 强度是乘性的 `qBound(0,1, Value×curve)`，旧写法低压力端被再乘一次
  Value（d=50 差 2×、d=10 差 10×、d=100 无误差）。
- 证据：单测按比值断言（如 d=50/Mnm=10 → `0,0.2;1,1;`，旧写法是 `0,0.1`；
  高度系 ×1.2 在比值里约掉）；另测 `Value×curve(0) == s_m`。
- **不写常数项、不写「已达标」**：PS 侧作用点（参数地板 vs alpha 地板）未量测（128A F-3），
  若 PS 是 alpha 地板，乘/减模式还需常数项。真实样本 depth_min 全为 0 → 产物无变化。

### 135-6 删除 legacy 开关（落地）

  （自 v1.2.0 起它就是默认，所以**默认产物无像素变化**，与 132 预测一致）。
- 正向断言（保留）：新用例断言旧符号 `_TEXTURE_FORMULA_ENV`、`_texture_formula`、
