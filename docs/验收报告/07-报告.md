## 六、遗留问题

1. **官方口径缺失**：`tools/imgdiff.py`（任务 03）与 `tests/baselines/krita/manifest.json`（任务 06A）执行时尚未落盘，
   本报告 §四 用的是替身指标。两者就绪后应复跑 23 张并改用官方口径，数字可能小幅变化（当前为 0.00%/1 灰度级）。
2. **真值图覆盖窄**：`research/krita结果/` 只有模式 0（d100）与模式 15（d10）两个组合，
   模式 1/10/14 没有真实 Krita 图可对照，只能靠 07A 单测里的手算数值断言。
3. **真值图 base 假设**：数据证明这批真值图等价于「不透明笔尖」（见 07A 报告 §五 假设 H1），
   但真实整笔渲染的笔尖 alpha 不是 1；整笔像素比对（任务 08）必须传入真实笔尖 alpha，否则会误报。
4. **未覆盖算法分支**：`NeutralPoint`≠0.5、`CutoffPolicy`≠0、`useSoftTexturing=true`、模式 2-9/11-13 均未实现（见说明文档 §6），
   当前 ABR 转换用不到；手改 KPP 的场景需要再补。
5. **`apply_depth` 的语义边界**：它只在线性模式（Multiply 类）等价于源码的强度处理；
   Height 系的深度是非线性参与，必须走 `blend(..., strength=depth)`——已写进 docstring 与说明文档，
   调用方若误用它处理 Height 系会得到偏差。
