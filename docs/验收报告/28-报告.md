## 一、任务结论

**✅ 完成（四类逐类给结论，全部带证据）**：四类参数各有独立一节；其中**两处第一轮语义被判错并纠正**（`Wtdg`≠宽度抖动=湿边；`Nose`≠喷嘴=噪点、`Rpt `=重复），并意外拿到一张 **PS 4CC ↔ 长名注册表（1950 条）** 作为机制性证据。
结论分布：**可映射 0 类 / 需改造 3 类（双笔刷、重复·喷枪、画笔姿态）/ 不可映射 3 项（湿边、噪点、投影）**。

| 类 | 结论 | 一句话理由 |
|---|---|---|
| ① 湿边 `Wtdg`/`wetEdges` | **不可映射** | Krita 410 个二进制里 `wetEdges`/`Wetness` **0 命中**；Krita 的「Wet」只是 MyPaint 引擎的 `smudge*`（沾色涂抹），与「单笔内边缘加浓」不是一件事；`krita_caps.json` `notes[0]` 明文把湿边列为「Krita 明确没有对应实现」 |
| ② 双笔刷 `dualBrush` | **需改造** | Krita 有 **masking brush**（实测 5 个预设键），但要建 `BlnM`→合成算子表、生成子预设、标定尺寸系数、且 `Cnt`/`scatterDynamics` 语义不可直搬 |
| ③ 噪点 `Nose` | **不可映射** | 第一轮误读为「喷嘴」；本轮定位为 `noise`（bool）。Krita 无噪点能力（`krita_caps.json` 未覆盖 + 二进制 0 命中） |
| ③ 重复/喷枪 `Rpt ` | **需改造（候选）** | 定位为 `repeat`（bool）。样本里它只出现在名字含「喷枪」的笔刷上 → 很可能是 PS 喷枪开关；Krita 有 `PaintOpSettings/isAirbrushing` + `/rate` 可接，但语义需 v0.3 直证 |
| ④ 姿态 `useBrushPose`+pose 子对象 | **需改造** | Krita 无「姿态」，但有 `xtilt/ytilt/ascension/declination/rotation` 传感器 + 旋转/圆度曲线；固定倾斜值无对应，只能降级 |
| ④ 投影 `brushProjection` | **不可映射** | ABR 里只是 bool（20/27 false、7 缺失、**0 支 true**），语义未定，Krita 无对应 |

## 五、遗留与风险（含「本任务未做的事」）

1. **Krita 源码行号缺口（影响发布说明的可引用性）**：本任务新增的 7 条 Krita 键（`MaskingBrush/Enabled`、`/MaskingCompositeOp`、`/MasterSizeCoeff`、`/UseMasterSize`、`/Preset/`、`PaintOpSettings/isAirbrushing`、`PaintOpSettings/rate`）只有**二进制串证据**，没有 invent.kde.org 行号锚点（本机无 Krita 源码树）。建议任务 22 用同一 commit `858d352` 补登进 `krita_caps.json`，否则发布说明只能写「本机实测存在」。
2. **`Nose` 的 bool ↔ 百分比冲突未解**：ABR 落盘是 bool，但 PS 代码里有把它当 `#Prc` 百分比读的路径（`0x143465f85`）。两者是否同一字段的不同层**未找到直证**（V-3-2）。不影响「不可映射」结论，但影响将来若有人想映射噪点强度时的量纲。
3. **`Rpt ` = 喷枪 只是强推断**（样本名共现 + 注册表 + PS 侧 bool 布局，三重一致），**没有**「开关喷枪→`Rpt ` 翻转」的直证。V-3-1 一条动态实验即可定论（需 PS，约 10 分钟）。
4. **`brushPoseTiltX/Y`、`useBrushPose` 三处仍无结构体偏移**（`ps_keys.json` `offset=null`，无 store/out_param 候选）。本任务用「同函数键引用 + ABR 落盘共现」间接佐证 pose 子对象布局，但**偏移本身未定位**。
5. **`dualBrush.BlnM` 取值未展开**：只确认它是 enum，没有枚举出「值 ↔ PS 模式名」全表 → 双笔刷的合成算子映射表还没法建（V-2-1）。这是「需改造」判定的最大未知。
6. **仓库根出现 `nul`（不是我建的，但会踩到所有人）**：`nul` 是 Windows 保留名，会让 **ripgrep 直接报错退出**（本任务实测：`rg: D:\...\nul: 函数不正确 (os error 1)`，导致全仓 grep 工具失败）。建议 lead 清理，否则后续任务的「全仓 grep」都会失败。另 `docs/验收报告/91-报告.md` 是未跟踪文件，不是我写的，请 lead 确认归属。
7. **本任务未做的事**：不改 `src/`（因此 `src/brush_converter/mapping.py:326-327` 里「喷嘴」这个错误告警文案**没修**，登记待 v0.4）；不改 `docs/参数矩阵.json`（归任务 23/29，差异见研究报告 §10 的 D-1..D-6）；不写 `docs/数据/candidates.json`；不做动态、不做像素比对；未把 1950 条注册表落成数据文件（属新增数据文件，待 lead 拍板）。
