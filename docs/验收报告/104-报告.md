## 五、Q1 / Q2 结论

### 5.1 Q1：塌缩组是「PS 判定等价」还是「采样点不够」？

- **参数层**：6 个目标模式各自独立 runtime id（Ovrl=17、CDdg=25、CBrn=26、linearBurn=31、height=40、linearHeight=41），
  H3 `<ADDR>` 经翻译器 `<ADDR>` 把 id 直接写入对象 `+4`，**没有归并逻辑**（单区域反汇编见 `ps-逆向-模式补强.md` §3.2）。
- **材料层**：depth 25/50/100 三点重跑后，5 个模式仍 3/3 饱和、linearBurn 仍与 Mltp 3/3 同哈希 →
  **塌缩不是采样点不够，是 base=1 判据材料的饱和/退化**。
- **口径**：像素分派函数未定位 → 只能写「**本口径下不可区分**」，不能写「PS 判定等价/同一算子」。
- 后续要拆开：换 base<1 的材料（半透明 dab / 压感边缘）。

### 5.2 Q2：无真值的 8 行是「没跑过」还是「跑不出来」？

- 8 行全部 UI 不可见 → 按 UI 门**不投入**（0 重跑 / 0 逆向）。
- `Add`（PS 落笔/保存报错）、`Rvrt`（PS 忽略枚举）、`Lght/Grdn/HdMxS`（PS 拒绝枚举）→ **跑不出来**。
- `SgdD/MgdD/HgdD` → 33 批喂了反序伪名导致**没跑过**（正名 `DdgS/DdgM/DdgH` 在任务 31 已证明可用），
  但 UI 不可见，按门仍不投入。
- `HdMxS` 的 `recheck_cmd = 暂无（待任务 104）`：**保留占位，不投入**（该行不在本任务写入范围，
  建议 105/113 改成「UI 不可见，不投入」并写原因）。
