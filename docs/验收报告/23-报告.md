### 2.3 校验脚本的九项检查（内容）

| 项 | 检查内容 | 失败时打印 |
|---|---|---|
| C1 | 文件存在/可解析/顶层是数组/非空 | 缺文件或 JSON 坏在哪 |
| C2 | 每行**恰好**六栏（缺栏、多栏、重复键都算错） | 「第 N 行（key=…）: 缺栏 X」 |
| C3 | 每栏非空（`sources` 至少一个取值） | 「栏 X 为空」 |
| C4 | `verdict` ∈ {可映射, 需校准, 无对应, 未定} | 非法值原文 |

| C6 | 与输入 JSON + 源码自洽：`re` ⇔ 在 `ps_keys.json`；`abr` ⇔ 在 `abr_keys.json`；`parser` ⇔ `src` 里有该字符串字面量；`krita_target` 与 `verdict`/`krita` 三方一致 | 逐行指出哪条不自洽 |

| C9 | md 与 `render_matrix_md.py` 生成结果逐字节一致（禁止手改 md） | 「被手改或未重生成」 |

### 3.5 基线阈值的取值依据（防回退）

`tools/check_matrix.py` 里钉了两个常量：

| 常量 | 值 | 依据 |
|---|---:|---|

### 3.6 与输入报告的口径差异（如实登记）

任务简报里记的「逆向有、仓库解析器未见 90 条」是按**任务 21 报告 §三**的算法（`125 − abr_keys 里 in_repo_parser=true 且落在 125 条内的 35 条 = 90`）得出的；
本矩阵改用**统一字面量判据**（`src/brush_converter/**/*.py` 的 ast 字符串字面量，排除 docstring）复算，得到 **87**：

```text
$ python -c "import json;d=json.load(open('docs/参数矩阵.json',encoding='utf-8'));print('re且无parser',sum(1 for r in d if 're' in r['sources'] and 'parser' not in r['sources']))"

$ python -c "import json;ak=json.load(open('docs/数据/abr_keys.json',encoding='utf-8'));d=json.load(open('docs/数据/ps_keys.json',encoding='utf-8'));ks={i['key'] for i in d};inr=[k['key'] for k in ak['keys'] if k.get('in_repo_parser')];print('报告21口径',len(ks-set(inr)),sorted(set(inr)-ks))"
报告21口径 90 ['InvT', 'Txtr', 'Wtdg', 'sampledData']
```

差额 3 条 = `brush` / `name` / `texture`：它们在 `src/` 里**确有字符串字面量**（`convert.py`、`mapping.py`），但 `abr_keys.json` 的 `in_repo_parser` 只能对 ABR 里出现过的键判真，而这三条只存在于逆向侧 ⇒ 旧口径把它们误算成「解析器未见」。
