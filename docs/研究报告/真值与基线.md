# 真值与基线（任务 33 技术纪要）

> 详细验收证据在 docs/验收报告/33-报告.md；本文只记「素材怎么造、口径是什么、坑在哪」。
> 目录：tests/baselines/mode/（图不入库）；清单：docs/数据/mode-batch.json；工具：tools/mode_batch.py。

## 1. 一句话

47 个 PS 纹理模式 × 6 组参数（3 档 depth × 2 组亮度/对比度），出一套 PS 真值（34 模式 × 6 = 204 张）
与一套 Krita 渲染基线（14 模式 × 6 = 84 张），并按顺序三等分成 A/B/C 三批给 34/35/36。

## 2. 口径（两边必须一致，改口径要整批重出）

| 项 | PS 侧 | Krita 侧 |
|---|---|---|
| 笔 | tests/定量测试专用.abr 的「定量测试用」（计算笔刷 Dmtr=200、硬度 100、间距 10） | 同一 ABR 预设走项目转换链生成的 .kpp |
| 纹理 | research/测试用纹理.png 原始字节定义图案（pattern 名 bc_mode_texture），textureScale=100%，invertTexture=true | 同一文件字节（内嵌时追加一个 tEXt 块改 md5，规避 Krita「同 md5 图案被静默禁用」的坑），Texture/Pattern/Scale=1.0 |
| 画布 | 100×100 / 72ppi / RGB 透明底 | 100×100，stroke=60，压感 1.0 |
| 落笔 | 画布中心 (50,50)→(50.4,50.4) 的 0.4px 路径（单章铺满） | 单 dab 横线（插件算起点 x0=(100-60)//2，圆盘覆盖整张画布） |
| 深度 | textureDepth = 10/60/100 | Texture/Strength/Value = depth/100（高度系 ×1.2 封顶 1.0） |
| 亮度/对比度 | textureBrightness/textureContrast = (0,0) / (−50,−50) | calibrated 公式：b_k = center_fix − b/255（Krita 亮度是减法）、c_k = k |
| 混合模式 | textureBlendMode（4CC 或字符串键） | mode-align.json 的 krita_value |

「深度/亮对比按映射算出的值」就是上表最后三行：Krita 侧不是照抄 PS 数字，而是走
src/brush_converter/kpp/preset_xml.py 的 calibrated 逆公式与 depth/100（高度系 ×1.2）。
tools/mode_batch.py 在生成 .kpp 时会断言「转换链算出的 TexturingMode == mode-align 的 krita_value」，
不一致直接失败（防止两边模式错配）。

## 3. 已知坑（都踩过，别再踩）

1. **PS 的整文件 sha256 不可复现**：PS 保存 PNG 时写 XMP iTXt 块（含创建时间），两次保存字节不同，
   但 IDAT 像素流与 Alpha 通道完全一致（实测 18/18 张 max Δ=0）。判确定性用 idat_md5 / alpha_sha256。
2. **mode-ids 的 jsx_readback 对「读取失败」的三条不可当期望值**（Lght/Grdn/HdMxS）：那是「没变时的读数」，
   拿它当期望会让回读校验假通过，把 height 的图当成 lightness 的图。必须按 status 一票否决。
3. **9 个字符串键模式写不进 textureBlendMode**（Rvrt/SgdD/MgdD/HgdD/SnrB/MnrB/HnrB/ttsD/Str）：
   调用成功、不报错、回读停在上一模式。
4. **Add('Add ') 能写进去但落笔报错**：「该功能可能无法用于此版本的 Photoshop」（jsx 第 238 行）。
5. **HdMxS 是 5 字符**：charIDToTypeID 只接受 4 字符，直接抛「非法参数」。
6. **Krita GUI 路线起的是 krita.com**，进程采样要匹配 krita* 前缀，否则会误判「没有 Krita 在跑」。
7. **高度/线性高度 d60/d100 会饱和**（Alpha 全 255，alpha_unique==1），拟合时要过滤。

## 4. 结果一览

| 项 | 数 |
|---|---|
| 判定模式 | 47（A16/B16/C15） |
| PS 真值 | 204 张 / 34 模式（失败 13 模式，原因见报告第五节） |
| Krita 基线 | 84 张 / 14 模式（0 失败） |
| 两侧都有、可像素比对 | 11 模式 × 6 = 66 对 |
| 单张耗时 | PS 1.9 s；Krita 15.05 s（min 14.27 / max 17.69） |
| 确定性 | Krita 18/18 sha256 相同；PS 18/18 像素相同（整文件不同，见坑 1） |

## 5. 复现

    "$PY" tools/mode_batch.py --plan
    "$PY" tools/mode_batch.py --ps --resume
    "$PY" tools/mode_batch.py --krita-build
    "$PY" tools/mode_batch.py --krita-render --resume
    "$PY" tools/mode_batch.py --recheck-ps --rehash --manifest
    "$PY" tools/mode_batch.py --verify-ps
    "$PY" tools/mode_batch.py --verify-krita

（PY=<LOCAL_APP_DIR>/anaconda3/envs/brushConverter/python.exe；PS 与 Krita 都是单实例，脚本自带 ps.lock / krita.lock 退避轮询。）
