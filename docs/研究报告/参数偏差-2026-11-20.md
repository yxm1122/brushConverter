## 2. 测量方法与不确定度

### 2.1 两侧出图

| 侧 | 路径 | 说明 |
|---|---|---|
| PS | 一个会话串行 21 张（`app.documents.add` 透明画布 → 改工具选项 → 路径描边 → PNG） | 复用已在运行的 PS 实例（`-r` 转发脚本）；工作目录通过 `%TEMP%/bc_measure_106_work.txt` 传给**已在运行**的实例 |
| Krita | GUI 插件真实渲染 21 张（`krita.com --nosplash` + 临时 pykrita 插件） | 单张 12.2–14.3s，21 张合计 **257.9s**；PS 21 张 **33.1s** |

### 2.2 指标定义

- **步长**（间距）：笔划沿 x 的周期性。候选来自 4 个信号（列 alpha 质量、alpha>8/64/160 的列高）
  × 2 种估计（扇贝极值间距、Hann 窗细网格直接 DFT 扫描）共 9–12 路，按 5% 聚类取票数最多簇的中位数。
  搜索窗 = **[0.5, 2.5]×标称步长**（能发现 ±2 倍偏差，同时排除「笔划两端包络」伪峰）。
  少于 2 票、或投票簇里没有任何信号轮廓调制 ≥0.5% → 该点判**不可判读**。
- **笔迹宽**（尺寸）：逐列 50% 阈值宽度（含亚像素插值），取「≥0.95×最大值」列的中位数。
  旧口径只看正中一列，在「间距=100%」时会落在相邻笔迹切点上（Krita size=20 实测中列 alpha 全 0），已修。
- **过渡宽**（硬度）：过质心行的 10%→90% alpha 落差，左右两侧取平均；硬边（落差 ≤2px）按绝对差判。
- **散布**：笔划带高（alpha>2 的包围盒高）与 Alpha 加权行标准差；判据用「增量 = 带高(v) − 带高(0)」。
- **角度**：Alpha 加权二阶矩主轴方向（mod 180°）+ 长短轴比。
- **缩放**：整图 alpha 差异 + 响应曲线 `R(s)=A(s)−A(100)` 的相对残差。

### 2.3 不确定度（本报告给所有数字配误差意识）

1. **PS 侧出图不完全确定**：同一 job 两次独立出图的 IDAT 不同（例：`spacing__nonsquare__v100`
   `f63b1b41…` → `61169965…`），实测步长复现性 **±1%**（同点两次：29.69↔29.42、58.87↔59.23、83.99↔84.51）。
   → 落在 2% 边界上的点（方形组 2.01%）按判据记「超阈」，但报告明确标注「在 ±1% 复现性内属临界」。
2. **估计量分歧**由 `spread_pct` 给出（同一簇内候选步长的极差/中位），本批 0.3–4.3%。
3. **笔尖足迹（dab 宽/高）不能跨侧比**：PS 对采样笔尖蒙版做了更硬的 alpha 截断，
   同一条方形笔尖（86×84）PS 侧渲染带高 32px、Krita 侧 59px。因此任务书 §1 那条
   「中心距 ÷ 笔尖像素宽度」在**纹理笔尖上无法成立**，本报告改用「步长比值 vs 长宽比」做对照（见 §4），
   足迹数据只作诊断量保留在 `results_spacing.json`。

## 4. 间距专项：方形 vs 非方形对照（与补平方有关 / 无关 / 证据不足）

### 4.1 对照表

| 组 | 笔尖蒙版 | 长宽比 | 补白后 | Krita/PS 步长比（10/50/100%） | 预测 = 长宽比 | 组内最大相对误差 |
|---|---|---|---|---|---|---|
| computed（无位图、无补白） | — | 1.000 | 无 | 1.000 / 0.982 / 0.994 | 1.000 | 1.88% |
| square（近方形采样） | 86×84 | 1.024 | 86×86（上下各补 1 行） | 1.017 / 1.020 / 1.013 | 1.024 | **2.01%**（临界） |
| nonsquare（非方形采样） | 183×143 | **1.280** | 183×183（上下各补 20 行） | **1.253 / 1.281 / 1.325** | **1.280** | **32.46%** |

### 4.2 结论：**与补平方有关**（B 级证据）

三条支撑，全部来自本次实测：

1. **分化只在非方形组出现**：非方形 24.6–32.5%，方形 1.3–2.0%，计算笔刷 0.55–1.88%；
   采用脚本内置判据（非方形 >2% 且 ≥2×方形）→ 判「与补平方有关」。
2. **偏差倍数 ≈ 长宽比**：非方形实测步长比 1.253/1.281/1.325，长宽比 183/143 = 1.280
   （三点都在 ±4% 内）；方形实测 1.013–1.020，长宽比 1.024；计算笔刷 0.982–1.000，长宽比 1.000。
3. **机理与既有假设一致**：PS 对非方形笔尖的间距基准是**渲染后短边**（143/183×112 = 87.5）。
   实测 PS 步长：10% = 8.78（预测 8.75，+0.3%）、50% = 43.72（预测 43.75，−0.1%）、
   100% = 84.51（预测 87.5，**−3.4%**，该点只有约 3.6 个周期、属少周期估计偏差）。
   前两点吻合到 0.3% 以内，第三点同向但偏低——所以这条机理写成「与数据一致」而不是「已被精确证实」。
   而补白把 Krita 的尺寸基准换成**正方形边长（=长边 112）**，于是 Krita 的步长与渲染尺寸同比例放大 ~1.28×。

### 4.3 这不是「已证实缺陷」，也不是 spacing 公式错

- 两侧各自都自洽：`步长 / 标称步长` 在 Krita 侧恒等于 1.00（100.84/100、198.16/200、6.00/6、30.01/30、60/60、11.00/11.2、56/56、111.94/112），
  说明 **`spacing = Spcn/100` 这条 1:1 换算本身没错**；错位发生在「笔尖尺寸基准」这一层
  （补白把短边基准换成长边基准），步长只是随尺寸一起被放大。
- 因此本报告只写「**与补平方有关**」，不写「补平方是 bug」；补平方代码一行未动。
- 使用者观感补充：非方形笔刷在 Krita 里**笔迹本身也大 ~1.3×**（同一条笔划包围盒高 PS 60–65 vs Krita 87–88），
  因此「间距不对」的观感里混着「笔迹变大」，107 若要修必须同时看这两项。

### 4.4 与任务书 §1 那条验证方法的差异（如实记录）

任务书要求量「相邻笔迹中心距 ÷ 笔尖像素宽度」，与「÷ 补白后正方形边长」对比。本次实测发现
**笔尖像素宽度不能跨侧比**：PS 对采样笔尖蒙版做了更硬的 alpha 截断（方形笔尖：PS 侧带高 32px、
Krita 59px；非方形：PS 60–65、Krita 87–88），这个「足迹」差本身是另一条差异（笔尖 alpha 语义），
会污染比值。故改用**纯位置量（步长）**做对照，并用「步长比 ≈ 长宽比」完成同一条推理；
足迹数据作为诊断量留在 `results_spacing.json` 的 `metric.ps.footprint / metric.kt.footprint`。

## 6. 「证不出来」的卡点

本轮六参数的**参数级结论没有「证不出来」**，但有一个**单点级不可判读**必须登记：

- **间距 computed 10%（Krita 侧）**：圆形软笔尖在 10% 间距下相邻笔迹重叠 90%，列高/列质量的轮廓调制
  只有 **0.22%**（PS 侧 1.2%，勉强可判读），低于 0.5% 的调制门 → Krita 侧步长判不可判读。
  要把它测出来需要：① 把笔划加长到 ≥3000px 做相干平均（噪声按 √N 降）；或
  ② 用硬边（硬度 100）方形笔尖做同间距对照（轮廓落差与 s/D 成正比，10% 时仍只有 ~1px，收益有限）；
  或 ③ 直接读引擎内部步长（需 REA 逆向，超出本任务范围）。
- 其余 8 个间距点、尺寸 3 点、硬度 3 点、散布 3 点、角度 3 点、缩放 3 点全部有数字。

## 7. 复现命令与产物

```bash

python tools/measure_deviation.py --param spacing --values 10,50,100

# 5) 只出 PS 图（调试，不启动 Krita）
python tools/measure_deviation.py --param spacing --values 50 --skip-krita
```
