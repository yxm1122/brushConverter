## 3. 不可承载（28 行）

### 3.1 双重画笔 7 行

`useDualBrush`、`BlnM`、`Flip`、`ui.dualBrush.size/spacing/scatter/bothAxes`。

Krita 的「双笔刷」是**另一种 paintop**（masking brush / 混合笔刷），不是像素引擎里的第二笔尖；
`krita_caps.json` 与 `DEFAULT_PARAMS` 均无第二笔尖的 diameter/spacing/scatter 字段。
映射会改变引擎类型，超出本任务范围，语义也不等价。

### 3.2 笔刷姿态 9 行

`useBrushPose`、`brushPoseAngle/Pressure/TiltX/TiltY`、`overridePoseAngle/Pressure/TiltX/TiltY`。

PS 2023+ 的 3D 笔刷姿态，Krita 5.3.3 无对应（无姿态输入源；传感器表里只有 tilt/pressure 等物理量）。

### 3.3 数量 3 行

`Cnt `、`count`、`countDynamics`。

Krita 散布只有 `ScatterValue`（0..5）与 `Scattering/AxisX|AxisY`（`krita_caps.json` adjacent 三条），
**没有「数量」**；`research/KisScatterOption.cpp` 全文只有 jitter，无 count。

### 3.4 湿边 3 行

`Wtdg`、`wetEdges`、`wtVr`。

Krita 像素引擎无湿边选项（湿边是其他引擎/后处理概念），`krita_caps.json` 无相关键。

### 3.5 纹理 2 行

`TxtC`（每个笔尖独立取纹理）、`protectTexture`（缩放时锁定图案坐标）。

Krita 纹理是画布空间图案：`Texture/Pattern/OffsetX|OffsetY|isRandomOffsetX|isRandomOffsetY`
（`krita_caps.json` texture 4 条）能近似「固定偏移」，但没有「每笔尖」与「保护纹理」开关；
按「近似 ≠ 承载」的口径判不可承载。

### 3.6 其余 4 行

| 行 | 原因 |
|---|---|
| `brushProjection` | 笔尖投影（PS 的 3D 投影），Krita 无 |
| `noise` | PS 杂色，Krita 像素引擎无杂色选项（fuzzy 传感器是随机源，不是杂色） |
| `smoothing` | PS 的平滑是工具选项；Krita 的平滑是稳定器/工具选项，不写在预设里（`krita_caps.json` 无键） |
| `mxVr` | 传递页的「混合」；Krita 的 Mix 属色彩涂抹引擎，像素引擎无 |
