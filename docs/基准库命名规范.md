# 基准库命名规范（brushConverter v1.2.0）

> 说明：本文档里的本机实测路径已占位化（`<LOCAL_APP_DIR>` = 本机软件安装目录，`<REPO>` = 仓库根），复现时请改成你自己的安装路径与仓库路径。

> 适用范围：tests/baselines/ 下所有当作「比对基准」的图片（ps/、krita/、handmade/）。
> 目的：只看文件名就知道「谁产的图、哪个模式、亮度/对比度多少」，不用打开图片或翻聊天记录。

## 1. 文件名格式（强制）

\`\`\`
<来源>__<笔刷或参数标识>__<模式>__<关键参数>.png
\`\`\`

- **分隔符固定为双下划线 \`__\`**（单下划线会被笔刷名里的下划线污染，无法解析）；
- 四段都不可省略；缺失信息写 \`none\`，不要留空段。
- 示例：\`ps__定量测试专用__线性高度__b0_c0.5.png\`
- 示例：\`krita__正片叠底_d100__multiply__b0_c0.png\`
- 示例：\`handmade__渐变圆__正片叠底__b0_c0.png\`

## 2. 四段各自写什么

| 段 | 取值 | 说明 |
|---|---|---|
| 来源 | \`ps\` / \`krita\` / \`handmade\` | 谁产的图；三种之外不许新增（要新增先改本规范） |
| 笔刷或参数标识 | 笔刷名或测试组标识 | 中文可用；空格改 \`_\`；\`正片叠底_d100\` 这类「模式_深度」也可 |
| 模式 | 纹理混合模式 | 用与 \`docs/parameter-mapping.md\` 第 7 节一致的名字：\`正片叠底\`/\`线性高度\`/\`hardMix\` 等 |
| 关键参数 | \`b<亮度>_c<对比度>\` | b = Krita 侧 Brightness（-1..1），c = Contrast（0..2）；例：\`b0_c0\`、\`b-0.10_c1.33\` |

> 为什么把亮度/对比度写进文件名：这两个参数正是本项目待定的映射（任务 07/13），
> 同一模式下不同 b/c 的图必须能一一对应，否则回归时无法判断「差异是哪组参数造成的」。

## 3. 登记要求（强制）

- 每张基准图必须在 \`tests/baselines/manifest.json\` 里有**一行**登记；
  **未登记的图不算基准**，任何比对结论都不得引用它。
- 登记字段至少：\`file\`、\`source\`、\`size\`、\`note\`；建议再记 \`mode\`、\`brightness\`、
  \`contrast\`、\`sha256\`、\`bytes\`（便于核对图片有没有被换过）。
- 团队分工：顶层 \`manifest.json\` 由任务 09/15 合并维护；产出图片的任务先写自己子目录的
  manifest（如 \`handmade/manifest.json\`、\`ps/manifest.json\`），由 09 汇总，避免并行写冲突。

## 4. 大图禁入（强制）

- **单张超过 2MB 的图禁止提交进 git**（仓库是 MIT 开源、会被反复 clone）。
- 替代做法（写进 manifest，不提交图片本体）：
  1. 图放本机固定目录（例如 \`%USERPROFILE%/brushconverter-baselines/\`）；
  2. manifest 里记绝对路径占位化后的形式、\`sha256\`、\`bytes\` 与**生成命令原文**；
  3. 引用时按 sha256 校验，换机器重新生成，而不是把大图塞进 git。
- 确实必须进仓库的大图：先在本任务报告里说明理由并算清仓库体积增量，等 lead 拍板（本版不批）。

## 5. 什么图才允许当基准

1. **可复现**：参数、脚本、Krita/PS 版本都记录在案；同一环境重跑能得到同一张图。
2. **版本锁定**：像素比对只在 Krita 5.3.3（\`<LOCAL_APP_DIR>\Krita (x64)\`）下有效；
   换版本必须重跑基准，不许拿旧图直接比。
3. **口径正确**：PNG 为 RGBA（RGB 可全黑），比对只看 Alpha；导出时不要做有损压缩/缩放。
4. **来源可追溯**：文件名四段齐全 + manifest 登记 + 生成命令（或脚本路径）可查。

## 6. 命名禁用与注意事项

- 不用空格、\`#\`、\`?\`、\`*\`、\`"\`、\`<\`、\`>\`、\`|\`（Windows 文件名非法或跨平台麻烦）。
- 不用 \`__\` 以外的连续分隔符；不要用中文全角括号做分隔。
- 同一参数组合只保留一张图；重跑覆盖时 manifest 的 sha256 必须同步更新。
