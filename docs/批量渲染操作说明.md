# 批量渲染操作说明（任务 06A · GUI 路线）

> 说明：本文档里的本机实测路径已占位化（`<LOCAL_APP_DIR>` = 本机软件安装目录，`<REPO>` = 仓库根），复现时请改成你自己的安装路径与仓库路径。

> 工具：`tools/krita_batch.py`（批量） + `tools/krita_render_runner.py`（单支外壳）
> 渲染原理见 `docs/Krita无头渲染说明.md`：**不是无头**，是「真实 Krita GUI 进程 + PyKrita 启动插件」自动落笔，
> 单支约 11–14 秒，批量串行执行（同一时刻只能跑一个，避免共用配置互相干扰）。

## 1. 常用命令

```bash
cd <REPO>
# 1) 批量真实渲染（默认 6 支代表笔：001/003/004/006/012/017），产出 PNG + manifest
PYTHONIOENCODING=utf-8 "<LOCAL_APP_DIR>/anaconda3/envs/brushConverter/python.exe" tools/krita_batch.py --render

# 2) 自定义清单（每行一个 .kpp 路径，支持相对/绝对）
python tools/krita_batch.py --render --list tests/baselines/krita/presets_render.txt

# 3) 只重跑上次失败项
python tools/krita_batch.py --render --only-failed

# 4) 只登记历史真值图（降级产物，不渲染）
python tools/krita_batch.py --register-historical
```

## 2. 输出与命名

- 图片：`tests/baselines/krita/krita__<笔刷名>__plain__s200x200_p1.0.png`
  （按 `docs/基准库命名规范.md` 四段式；笔刷名取资源库预设名清洗后结果，去首部序号、非法字符换下划线）
- 批次结果：`tests/baselines/krita/render_attempts.json`（每支的 preset/status/elapsed_s/reason/timeout）
- 清单：`tests/baselines/krita/manifest.json`（**合并写入**：rendered 在前、historical 在后）

### manifest 字段（每条）

| 字段 | 含义 |
|---|---|
| `file` | 基准图文件名（失败项为 null） |
| `source` | 固定 `krita` |
| `preset` | 资源库预设名（真实渲染）或 `none`（历史图） |
| `preset_file` | 对应 `.kpp` 文件名（真实渲染） |
| `size` | 画布尺寸，如 `200x200` |
| `pressure` | 压感（历史图为 null） |
| `status` | `rendered` / `failed` / `historical` |
| `elapsed_s` | 该支渲染耗时（秒；历史图为 null） |
| `alpha_nonzero` | Alpha 非零像素数（落笔证据；0 视为失败） |
| `sha256` / `bytes` | 文件哈希与大小（核对有没有被换过） |
| `renderer` | `krita-gui-plugin`（真实渲染）/ `krita-gui-historical`（历史图） |
| `route` | 真实渲染固定 `gui` |
| `reason` | 失败原因（stderr/结果 JSON 中的原因，仅 failed 项） |

## 3. 失败处理（写死的规则）

1. **单支失败不中断整批**：每支独立 try/except，失败写 `status=failed` + `reason`，继续下一支；
2. 失败项**不从清单里删**，`file` 为 null 且保留原因，便于 `--only-failed` 重跑；
3. **超时算失败**（`timeout=true`），绝不当成功；
4. 全部失败时进程退出码 = 1，并打印原因汇总；部分成功退出码 = 0；
5. `alpha_nonzero=0` 视为落笔失败（按失败记）。

## 5. 规模与耗时

- 单支 11–14 秒（含 Krita 启动约 3–4 秒 + 落笔导出约 1–2 秒 + 退出）；
- 6 支一轮约 74 秒；**19 支全量估算 ≈ 4 分钟**（19 × 12 秒），远低于任务书的 20 分钟上限；
- 若单支超过 75 秒（外壳默认 GUI 超时），会被判超时并重试一次，仍失败则记为 failed。


## 7. 注意事项

1. 运行期间会闪出 Krita 窗口（正常）；不要在批量运行同时手动开 Krita；
2. 批量是串行的，**不要并发跑两个 `--render`**（会争用同一份 kritarc/插件目录）；
3. 外壳会在会话前后备份/还原 `%LOCALAPPDATA%/kritarc` 与 `%APPDATA%/krita/resourcecache.sqlite`，异常中断后建议核对：
   `grep -c enable_bc_auto_render "$LOCALAPPDATA/kritarc"` 应为 0，`ls "$APPDATA/krita/pykrita" | grep bc_auto_render` 应无输出。
4. 历史真值图（historical）是降级期登记的 23 张，**不是本工具渲染**，比对时按 `renderer` 字段区分。
