## 1. 结论摘要

1. 纹理掩码预处理（灰度换算 → 亮度 → 对比度 → 截断 → 反相）已按
   `research/krita_texture/KisTextureMaskInfo.cpp` 的 `recalculateMask()` 逐行复刻，
   实现为 `apply_three()`（三步函数 `apply_invert/apply_brightness/apply_contrast` 可单独调用）。
2. 掩码混合（5 种模式）与深度（强度）已按 Krita 上游
   `libs/ui/tool/strokes/KisMaskingBrushCompositeOp.h` + `kis_texture_option.cpp` 复刻，
   实现为 `blend()` / `apply_depth()` / `compute_mask()`；未实现模式显式抛
   `NotImplementedError` 并带枚举号。
3. 实测：`research/krita结果/` 的 **23 张 Krita 真值图全部复现成功**——
   差异比例（>2 灰度级）**0.00%**、最大差值 **≤1 灰度级**、平均绝对误差 **≤0.663 灰度级**。
   这 23 张覆盖模式 0（Multiply，深度 100%）与模式 15（Linear Height (Photoshop)，深度 10%），
   以及亮度 / 对比度的多个取值。

## 3. 三步公式与源码对应表

`mask` 为 0..1 的 float32。

| 步骤 | 公式（本模块） | 源码位置 | 我们的函数 |
|---|---|---|---|
| 灰度换算 | `gray = (R*11 + G*16 + B*5) // 32`（整数除法） | `KisTextureMaskInfo.cpp` L189 | `texture_mask_from_rgba()` |
| 透明合成 | `mask = (gray/255)*alpha + (1-alpha)` | 同文件 L187、L190 | `texture_mask_from_rgba()` |
| 亮度 | `mask = mask - brightness` | 同文件 L192 | `apply_brightness()` / `apply_three()` |
| 对比度 | `mask = (mask - 0.5) * contrast + 0.5` | 同文件 L194 | `apply_contrast()` / `apply_three()` |
| 截断 | `>1 → 1，<0 → 0` | 同文件 L196-197 | `apply_three()` 内 L192+L194 之后统一截断 |
| 反相 | `mask = 1 - mask` | 同文件 L199-201 | `apply_invert()` / `apply_three()` |
| 收尾约束 | `qBound(0, mask, 1)` | 同文件 L203 | `apply_three()` 末尾 |
| 中性点（默认 0.5=恒等） | 分段线性：`np==1` 或 `(np!=0 且 v<=np)` 时 `v/(2np)`，否则 `0.5+(v-np)/(2-2np)` | 同文件 L209-213 | **未实现**（见 §6） |
| cutoff 裁剪（默认 policy=0 不生效） | `policy==1/2` 时按 cutoffLeft/Right 透明或不透明 | 同文件 L215-226 | **未实现**（见 §6） |

方向提醒（源码为准，别按直觉改）：
- **亮度是减法**：`brightness` 越大，掩码越暗（`maskValue -= m_brightness`）。
- **对比度以 0.5 为中心且 `contrast>1` 是拉开**：`0.4→0.3`、`0.6→0.7`（contrast=2）；
  `contrast=1` 是恒等；`contrast=0` 全部压到 0.5。

## 4. 混合模式表（枚举号 ↔ 名称 ↔ 公式）

`base` 是笔尖 alpha（0..1），`tex` 是 §3 处理后的掩码（0..1），
`depth` 是纹理深度（0..1，Krita 里即 `Texture/Strength/Value`），
`strength` 为源码的强度参数，按 8-bit 通道量化：
`s = round(depth*255)/255`（C++ `qRound` 语义，用 `floor(x+0.5)` 实现）。

| 枚举号 | 名称 | 公式（0..1 归一化） | 源码位置 |
|---|---|---|---|
| 0 | Multiply | `src * dst * s` | `KisMaskingBrushCompositeOp.h`：`KIS_MASKING_BRUSH_COMPOSITE_MULT, true, false` 分支 `Arithmetic::mul(src, dst, strength)` |
| 1 | Subtract | `max(0, dst - (src + (1 - s)))` | 同文件 `KIS_MASKING_BRUSH_COMPOSITE_SUBTRACT, true, false` 分支 |
| 10 | Hard Mix (Photoshop) | `(src + dst*s > 1) ? 1 : 0`（严格大于） | 同文件 `KIS_MASKING_BRUSH_COMPOSITE_HARD_MIX_PHOTOSHOP, true, false` → `CFHardMixPhotoshop::composeChannel(src, mul(dst, s))`（`CFHardMixPhotoshop` 定义在 `libs/pigment/compositeops/KoCompositeOpFunctions.h`） |
| 14 | Height (Photoshop) | `clamp(dst*(10*s) - src, 0, 1)` | 同文件 `KIS_MASKING_BRUSH_COMPOSITE_HEIGHT_PHOTOSHOP, true, false`（`weight = 10*strength`） |
| 15 | Linear Height (Photoshop) | `md = dst*(10*s)`；`clamp(max((1-src)*md, md-src), 0, 1)` | 同文件 `KIS_MASKING_BRUSH_COMPOSITE_LINEAR_HEIGHT_PHOTOSHOP, true, false`（`weight = 10*strength`） |

模式号 → 算子 id 的分派在 `kis_texture_option.cpp` L335-350（switch），
强度在 L312 计算（`qreal strength = m_strengthOption.apply(info);`），
L352-354 用 `createForAlphaSrc(id, ..., strength, useSoftTexturing)` 建算子，
L382-384 逐块调用 `composite()`。本模块固定 `useSoftTexturing=false`（KPP 默认值）。

其余枚举（2 Lightness、3 Gradient、4 Darken、5 Overlay、6/7 Dodge/Burn、
8/9 Linear Dodge/Burn、11 Hard Mix Softer、12/13 Height/Linear Height）
**一律显式抛 `NotImplementedError("未实现的 Krita 纹理混合模式枚举号: N（已实现: [...]")`**，
不静默回退，避免比对「看起来正常」。

## 5. 深度合成的位置

深度不是「最后再乘一次」那么简单，源码把它作为强度放进合成算子：

- `kis_texture_option.cpp` L312：`qreal strength = m_strengthOption.apply(info);`
  （`bVTy==0` 时就是 `Texture/Strength/Value`，即 `textureDepth/100`）
- L352-354：`createForAlphaSrc(..., strength, m_useSoftTexturing)`
- 算子里 `StrengthCompositeFunctionBase` 把 qreal 强度量化成通道值：
  `scaleToA(strength)`（quint8 即 `round(strength*255)`）
- Height / Linear Height 用 `weight = 10*strength`，于是**深度是非线性参与**的。

因此本模块：
- `apply_depth(mask, depth)` 只做「线性模式」等价的 `mask * s`（Multiply / Darken 类可用）；
- `compute_mask()` 把 `depth` 直接传给 `blend(..., strength=depth)`，对 5 种模式都按源码路径算。

实测证据（见 §7）：深度 10% 若按「直接乘」假设（w=1.0）误差 MAE=4.97~5.0 灰度级；
按 `s=round(0.1*255)=26`、`weight=10*s=260` 即 `w=260/255` 时误差为 0。

## 6. 未覆盖部分

| 未覆盖项 | 原因 | 影响 |
|---|---|---|
| 中性点 `NeutralPoint`（源码 L209-213） | 默认 0.5 时该段是恒等变换；KPP 默认即 0.5，ABR 也无对应参数 | 非 0.5 的手调 KPP 会有偏差 |
| cutoff 裁剪（L215-226） | 默认 `CutoffPolicy=0` 不生效，ABR 无对应参数 | 手调 cutoff 的 KPP 不覆盖 |
| `useSoftTexturing=true` 分支 | KPP 默认 false，ABR 无对应参数 | 手工勾选 Soften 的 KPP 不覆盖 |
| 模式 2-9、11、12、13 | ABR 映射只落到 0/1/10/14/15；其余按要求显式抛错 | 手改 TexturingMode 的 KPP 会报错（有意为之） |
| 纹理缩放 `Scale` 与平铺偏移 `OffsetX/Y`、随机偏移 | 属于「摆放/裁剪」而非「掩码数值」，本模块不处理；比对时由调用方先按 scale/offset 平铺裁剪到目标尺寸 | 比对脚本需自行处理取样 |
| 8-bit 量化 | 本模块用 float32 连续值，只有深度强度做了 8-bit 量化 | 与真值图存在 ≤1 灰度级舍入差 |
| 笔尖 alpha（base） | `base` 由调用方提供；`compute_mask` 默认全 1（不透明笔尖） | 整笔像素比对时需传入真实笔尖覆盖度 |

## 7. 实测校验（只报数）

### 7.1 方法

- 纹理：`research/测试用纹理.png`（64×64、全不透明、灰度纹理），
  用 `texture_mask_from_rgba()` 转成 0..1 掩码，按 100×100 目标尺寸以偏移 (0,0) 平铺；
- 真值：`research/krita结果/` 23 张 100×100 RGBA，RGB 全 0、信息在 Alpha；
- 预测：`compute_mask(tex, invert=False, brightness=b, contrast=c, mode=模式, depth=深度)`，
  其中 `base` 用默认全 1（实测证明这批真值图等价于不透明笔尖，见 7.4）；
- 指标（先各自四舍五入到 8-bit 再比较）：
  **差异比例** = `|Δ| > 2` 灰度级的像素占比；**最大差值** = `max|Δ|`；另附 **MAE**。
  （任务书要求用 `tools/imgdiff.py`，但执行时该文件尚不存在（`tools/` 下只有并行任务的
  `verify_entry.py`/`krita_probe/*`），故用上述等价定义在命令行内计算；定义已写死，
  任务 03 的 `imgdiff.py` 就绪后应改用统一口径复核。）

### 7.4 关键佐证：真值图是「纯蒙版」而不是带笔尖形状的整笔

- `正片叠底_d100/b0_c0.png` 的 Alpha 与按源码算出的掩码**逐像素完全相等**（MAE=0，最大差值=0）。
  若笔尖是软边（base<1），乘法结果不可能逐像素相等 → 说明该批真值图的 base≡1。
- 平铺偏移扫描（dy,dx 各 0..63）最优为 (0,0)，此时「真值/掩码」比值的相邻差均值 0.0073；
  若假设纹理被拉伸到 100×100，比值标准差 1.069、粗糙度 1.45，明显不成立。

import sys, glob, os, re; sys.path.insert(0, ".")
import numpy as np
from PIL import Image
from tools.texture_mask import texture_mask_from_rgba, compute_mask, MODE_MULTIPLY, MODE_LINEAR_HEIGHT_PHOTOSHOP
tex = texture_mask_from_rgba(np.array(Image.open("research/测试用纹理.png").convert("RGBA")))
T = tex[np.ix_(np.arange(100)%64, np.arange(100)%64)]
def truth(p): return np.array(Image.open(p).convert("RGBA")).astype(np.float64)[:,:,3]/255.0
def metric(pred, ref):
    d = np.abs(np.clip(np.rint(pred*255),0,255) - np.rint(ref*255))
    return (d>2).mean()*100, d.max(), d.mean()
for pat, mode, depth in [("research/krita结果/正片叠底_d100", MODE_MULTIPLY, 1.0),
                         ("research/krita结果/线性高度（photoshop）_d10", MODE_LINEAR_HEIGHT_PHOTOSHOP, 0.1)]:

        name = os.path.basename(p); m = re.match(r"b(-?[0-9.]+)_c([0-9.]+).png", name)
        b, c = (0.0, 1.0) if name == "b0_c0.png" else (float(m.group(1)), float(m.group(2)))
        r, mx, mae = metric(compute_mask(T, False, b, c, mode, depth), truth(p))
        print(f"{os.path.basename(pat)}/{name} ratio={r:.2f}% max={mx:.0f} MAE={mae:.3f}")
